# STACK

## Core
- **Framework:** React 19 (`react`, `react-dom`)
- **Build Tool:** Vite
- **Language:** JavaScript (`.jsx`, `.js`)
- **Styling:** Vanilla CSS (`index.css`, `App.css`) and Inline Styles

## Libraries
- **Animations/Effects:** 
  - `framer-motion` (Declarative animations)
  - `react-tsparticles` & `tsparticles` (Particle background effects)
  - `typewriter-effect` (Typing animation in Hero section)
  - `react-parallax-tilt` (Tilt effects on hover)
- **Icons:** 
  - `react-icons`
  - `lucide-react`

## Development Tools
- **Linter:** ESLint (with `eslint-plugin-react-hooks`, `eslint-plugin-react-refresh`)
- **Package Manager:** npm
